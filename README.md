# Robótica · 3.º ESO

Unidad didáctica interactiva de **Robótica para 3.º ESO** (Tecnología).
Material del curso de [Jaime Aniorte · SoyTecnoTeacher](https://soytecnoteacher.com).

🌐 **Acceso online:** https://nesorct.github.io/robotica-3-eso/

## Contenido

- **Sesión 1** — Máquina vs. robot · Lazo abierto/cerrado · Clasificación · Robots en Murcia y España
- **Sesión 2** — Leyes de Asimov (incl. Ley Cero) · Regulación EU · Glosario · Balance del curso

## Cómo usarlo

1. El alumno abre la web, escribe su nombre y va respondiendo las preguntas.
2. Al terminar cada sesión, pulsa **"Exportar a PDF"** y entrega el documento.
